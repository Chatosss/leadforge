Sessões de Reels

Ative uma conta para abrir o Reels na sessão autenticada. Os vídeos passam sozinhos ao terminar; você pode rolar, curtir ou salvar à mão quando quiser. Desative para fechar a janela e liberar o perfil.

Rolagem: quando o vídeo termina, a janela passa sozinha para o próximo Reel (com uma pausa curta); vídeo com erro ou travado também é passado. O sistema não curte, não comenta e não salva publicações. Enquanto a sessão estiver aberta, a prospecção dessa conta fica bloqueada para evitar conflito de perfil.
Leve: os vídeos tocam na menor qualidade e sem som, e todas as contas abrem num navegador só, uma de cada vez.

Agendar o aquecimento

Configurações

Modo de envio

Decide se as mensagens saem para contatos reais ou apenas para os destinos de teste. É a única trava que vale para os três canais ao mesmo tempo.

Backup e migração

Leva os seus dados — bancos, contas conectadas, sessões logadas, nichos, materiais e logs. O programa em si não entra: ele vem do instalador.

Importar numa instalação nova

Escolha um pacote .zip gerado aqui. Antes de escrever qualquer coisa, o painel guarda uma cópia do estado atual — restaurar substitui os dados de agora.

Diagnóstico do sistema

Onde cada coisa mora. Serve para responder "o painel está olhando o arquivo certo?" sem abrir terminal.
